BAAPRE COMMUNICATIONS — GODADDY UPLOAD

Files:
- index.html        Main website
- logo.jpg          Baapre logo
- favicon.jpg       Browser icon
- robots.txt        Search-engine crawler instructions
- sitemap.xml       Search-engine sitemap

GoDaddy:
1. Open GoDaddy > Web Hosting / cPanel Hosting > Manage.
2. Open cPanel > File Manager.
3. Open the website's public_html folder.
4. Upload all five files/folders from this package into public_html.
5. Make sure index.html is directly inside public_html.
6. Visit https://baapre.co.in/

SEO:
- robots.txt and sitemap.xml are already configured for baapre.co.in.
- After the site is live, add https://baapre.co.in/sitemap.xml to Google Search Console.
- Allow some time for Google to crawl and index the page.
